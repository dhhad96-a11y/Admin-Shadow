How validation works

Validation checks: key exists → status is active → not expired → remaining uses > 0 → binding rules (if any). When "Validate & Bind" is used and the key has binding enabled, the first successful use locks it to the provided Device ID or IP. Every validation attempt is recorded in Usage Logs.
